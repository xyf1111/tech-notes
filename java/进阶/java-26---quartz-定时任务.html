Java 26 — Quartz 定时任务

Quartz 是功能强大的 Java 调度框架，比 @Scheduled 注解更灵活，支持动态增删改查任务。

核心概念

组件职责
Job执行实际任务的对象，需实现 execute() 方法
Trigger规定任务执行时间、频率的对象（如 Cron 表达式）
Scheduler管理调度 Job 和 Trigger，负责绑定与执行
