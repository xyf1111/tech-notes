Function（服务员）：数据转换，一进一出

Function<T, R> 接收类型 T 的参数，返回类型 R 的结果，典型的数据转换器。

示例

JDK 源码

  • apply(T)：抽象方法，执行转换
  • compose：先执行入参函数，再执行当前函数
  • andThen：先执行当前函数，再执行入参函数
  • identity：返回输入本身

Sa-Token 实战：创建 SaSession

接收 SessionId 字符串，返回 SaSession 对象，用于定制 Session 创建策略。

应用场景

场景说明
类型转换Function<String, Integer> strToInt = Integer::parseInt;
函数组合strToInt.andThen(intToStr) 将多个转换串联
数据加工对输入进行清洗、映射、格式化后再输出

Predicate（菜单选择标准）：条件判断，返回布尔值

Predicate 即断言，接收一个参数，返回 boolean 值，用于条件过滤。

示例

JDK 源码

  • test(T)：抽象方法，执行条件判断
  • and / or / negate：逻辑组合，类似于 && / || / !
  • isEqual：创建相等性断言
  • not：对现有断言取反

应用场景

场景说明
过滤集合list.stream().filter(isEven).collect(...)
数据校验判断数字是否为偶数、字符串是否匹配正则
组合条件isEven.and(isPositive) 实现多条件筛选
