注意点

  1. 不能对 boolean 进行类型转换
  2. 不能把对象类型转换成不相关的类型
  3. 高容量→低容量需强制转换
  4. 转换时可能出现内存溢出或精度问题

变量

变量是程序中最基本的存储单元，三要素：变量名 + 变量类型 + 作用域

变量作用域

类型位置生命周期
类变量 (static)类中，方法外随类加载而存在
实例变量类中，方法外随对象创建而存在
局部变量方法或代码块内方法执行期间

命名规范

目标规范示例
类成员变量首字母小写 + 驼峰monthSalary
局部变量首字母小写 + 驼峰userName
常量全大写 + 下划线MAX_VALUE
类名首字母大写 + 驼峰GoodMan
方法名首字母小写 + 驼峰runRun()
