Java 工具 19 - IDEA 插件大汇总

汇总 JetBrains IDEA 上约 50 款实用插件，按「强烈推荐 / 美化 / 代码生成 / 功能提效 / 扩展增强」分类整理，覆盖代码补全、规范检查、MyBatis 增强、Git 辅助、时序图与字节码阅读等场景，帮助 Java 开发者按需安装、快速武装自己的 IDE。

俗话说，工欲善其事，必先利其器。想要提升编程开发效率，必须选择一款顺手的开发工具。对于 Java 开发者，JetBrains IDEA 无疑是目前最主流的开发工具，既简单易用、又强大灵活，并且可以通过安装插件全副武装。

安装方式：打开 Settings（macOS 为 Preferences）→ Plugins → 在 Marketplace 中搜索插件名 → Install → 重启 IDE 生效。

其中 Key Promoter X、Arthas Idea、GenerateAllSetter、GenerateSerialVersionUID、GsonFormat、Lombok、Rainbow Brackets、CodeGlance、GitToolBox、Translation 等精选插件的使用场景详见 Java 工具 15 - IDEA 高效开发技巧。

什么，IDEA 太贵用不起？如果是学生党，可以免费使用全系列产品哦~ 地址：https://www.jetbrains.com/shop/eform/students
