Java 学习路线（零基础到精通）

开篇介绍

Java 是拥有 20 多年历史的老牌编程语言，以”一次编写，到处运行”为特性，是企业级应用开发的首选语言之一。

应用场景

企业管理系统、电商平台、社交应用、游戏后台、大数据处理系统、AI 应用（智能客服、AI 助手等）。

就业方向

  1. Java 后端开发工程师：负责服务端业务逻辑开发，最主流的就业方向
  2. Java 全栈开发工程师：后端 + 前端，能独立完成完整项目
  3. 安卓开发工程师：使用 Java/Kotlin 开发安卓应用
  4. 大数据开发工程师：使用 Java 进行大数据处理（Hadoop、Spark、Flink）
  5. 架构师：负责系统整体设计和技术选型
  6. AI 应用开发工程师：Java + AI 框架（LangChain4j 等）开发 AI 应用

阶段 1：编程语言基础

目标：培养兴趣、快速上手，能运行和编写简单的 Java 程序。

Java 编程基础（45 天）

知识点

  • Java 特点与环境搭建
  • IDEA 开发工具（新建项目、运行调试、界面配置、插件管理）
  • Java 基础语法：数据类型、流程控制
  • 数组
  • 面向对象：方法、重载、封装、继承、多态
  • 抽象类、接口、枚举
  • 常用类：String、日期时间
  • 集合类、泛型、注解
  • 异常处理、多线程、IO 流、反射

学习建议

  1. 坚持每天学习 2-3 小时，保持连贯性
  2. 多敲代码，不要只看视频不动手
  3. 学会使用 Debug 调试，学会看报错信息
  4. 善用 AI 工具辅助学习，但不要完全依赖
  5. 不要死记硬背语法和 API，理解为主，多用自然记住

  4. final 关键字的作用
  5. 介绍 Java 的集合类

Java 8 及新版本特性（3 天）

知识点

Java 8 核心特性（必学）：

  • Stream API
  • Lambda 表达式
  • 新日期时间 API
  • 接口默认方法
  • Optional 类

Java 新版本特性（了解）：

  • Java 17：Record 类、Sealed Classes、模式匹配增强
  • Java 21（LTS）：虚拟线程（Virtual Threads）、序列集合
  • Java 21 之后：更多语法糖和性能优化

学习建议

Java 8 是企业开发中最主流的稳定版本，Lambda 和 Stream API 能让代码更简洁优雅。新版本特性可在掌握 Java 8 核心后按需了解，特别是虚拟线程对 I/O 密集型应用的提升显著。

为什么大量存量项目仍停留在 Java 8（版本选择考量）：

  • 版本分布现状：JetBrains 的调查显示，Java 8 长期是最受欢迎的 LTS 版本，占比高达 70% 以上；Java 11 作为另一个 LTS 稳定版本排名第 2，约占 30%——两个版本加起来基本覆盖了全部 Java 开发者，即使更新的 LTS（如 Java 17）发布，愿意升级的企业也很少。
  • 兼容性：企业存量项目与第三方类库大多基于 Java 8 及以下，强升 JDK 难保证行为完全一致（真实案例：JDK 8 升 11 后项目能跑，但 Excel 导出功能部分字符乱码，折腾很久）——谨记「程序能运行，就不要动它」。
  • 稳定性：Java 8 已经过成千上万个企业项目检验；换新版本可能遇到莫名其妙的线上问题，规模较大的项目慎用太新的东西。
  • 生态与资料：网上教程、Bug 解决方案几乎都基于 Java 8，高版本哪怕同样的代码可能跑不起来，且搜不到现成方案，对经验不足的同学很致命（冷门语言同理）。
  • 升级收益不明显：新版本多是依赖升级与锦上添花（如 Spring Boot 3.0 的 GraalVM 原生镜像、可观测性提升），不足以成为改变开发习惯的契机。
  • 补充：以上是存量项目的保守视角；新项目可直接上 Java 17 / 21（LTS），Spring Boot 3 已是当前主流，详见 Java 44 - Spring Boot 学习路线。

阶段 3：企业开发基础（60+ 天）

目标：学习实际后台开发的基础技术和框架，能独立开发具有完整功能的 Java Web 项目。

MySQL 数据库（7 天）

企业中大部分业务数据使用关系型数据库存储，MySQL 是主流也是面试重点。

知识点

  • 索引（必学）：索引类型、原理、优化
  • 事务（必学）：ACID 特性、隔离级别
  • 锁机制：行锁/表锁、乐观锁/悲观锁
  • 设计数据库表（必学）：三大范式、表关联设计
  • 性能优化

经典面试题

  1. MySQL 索引的最左原则

  3. 有哪些优化数据库性能的方法？

容器化（7 天）

将应用和环境封装，相互隔离独立部署。

知识点

Docker： 容器概念、镜像、部署服务、Dockerfile、Docker Compose K8S（了解）： K8S 架构、Pod、部署应用、集群管理

学习建议

Docker 是后端开发标配，必须学。K8S 学习成本较高，可先不学。

经典面试题

  1. 什么是容器？
  2. 使用 Docker 有哪些好处？

学习资源

  • 狂神说 Docker 最新超详细版教程（B 站）
  • 《深入浅出 Docker》
  • Docker — 从入门到实践

阶段 5：项目实战

目标：综合所学技术从 0 到 1 开发上线一个完整的个人项目，可写入简历。

学习建议

  • 至少做 2 个完整项目：1 个简单（如管理系统）+ 1 个复杂（含微服务、缓存、消息队列等）
  • 必须从 0 到 1 手写，不要只下载源码跑一遍
  • 边做边记录问题和解决方案，面试时能派上用场

项目推荐

入门级：

  1. 用户中心项目：前后端完整项目，学习项目开发流程和上线方法
  2. 伙伴匹配系统：移动端网站，Redis、事务、并发编程
  3. AI 编程助手：入门 AI 应用开发，LangChain4j

进阶级： 4. 智能协同云图库：文件存管、权限控制、实时协同 5. AI 答题应用平台：分库分表、分布式锁、响应式编程 6. 智能面试刷题平台：Redis 多级缓存、Elasticsearch、Sentinel 流控 7. 代码生成器共享平台：命令行开发、模板引擎、设计模式

架构进阶： 8. API 开放平台：SDK 开发 + API 签名认证 + Dubbo + Gateway 9. OJ 判题系统：多种设计模式 + 微服务改造 + Docker 代码沙箱 10. 手写 RPC 框架：从 0 到 1 开发轮子，提升架构设计能力

公开视频项目：

  • 尚硅谷谷粒学院（微服务+全栈在线教育）
  • 黑马电商项目、传智健康、万信金融、好客租房

常用工具类库

  • Guava：谷歌 Java 工具库
  • Hutool：Java 工具集
  • Lombok：自动生成 getter/setter
  • OkHttp：HTTP 客户端
  • EasyExcel：Excel 处理库
  • JUnit + Mockito：单元测试
  • Arthas：Java 诊断工具
  • Caffeine：高性能缓存库

阶段 6：Java 高级

目标：不满足于能用，深入和广泛学习，实现高质量代码和优秀架构。

并发编程（21 天）

利用有限的系统资源提高系统性能，大厂面试考察重点。

知识点

传统并发编程（必学）：

  • 线程和进程、线程状态
  • 并行/并发、同步/异步
  • Synchronized、Volatile、Lock 锁
  • 死锁、可重入锁
  • 线程安全、线程池
  • JUC 使用、AQS、CAS、ForkJoin

新特性（了解）：

  • 虚拟线程（Java 21，轻量级线程，提升 I/O 密集型应用并发性能）
  • 结构化并发

经典面试题

  1. volatile 关键字的作用
  2. 使用线程池有哪些好处？
  3. 线程池参数如何设置？
  4. 什么是线程安全问题，如何解决？
  5. 介绍 synchronized 的锁升级机制
  6. CopyOnWriteArrayList 适用于哪种场景？

学习资源

  • 尚硅谷 JUC 并发编程（B 站，短精新）
  • 黑马 Java 并发编程（B 站，全面深入）
  • 《Java 并发编程实战》
  • 《Java 并发编程艺术》

JVM（30 天）

深入了解 Java 虚拟机，掌握性能调优方法。

知识点

  • JVM 内存结构
  • 类加载机制（类加载器、双亲委派模型）
  • 垃圾回收（回收器、策略、算法、StopTheWorld）
  • 字节码
  • JVM 性能调优（工具、参数设置）
  • 线上故障分析

经典面试题

  1. 介绍 JVM 的内存模型？
  2. JVM 内存为什么要分代？
  3. 介绍一次完整的 GC 流程
  4. 介绍双亲委派模型，为什么需要它？

学习资源

  • 尚硅谷宋红康 JVM 全套教程（B 站）
  • 狂神说 Java JVM 快速入门篇（B 站，适合面试速成）
  • 《深入理解 Java 虚拟机（第三版）》—— JVM 神书
  • Arthas 开源 Java 诊断工具

Java 高级知识

  • 动态代理
  • Java 探针
  • 字节码
  • UnSafe 类

架构设计

分布式

分布式理论： CAP、BASE 一致性算法： Raft、Paxos、一致性哈希 分布式事务： 2PC、3PC、TCC、本地消息表、MQ 事务消息 分布式实践： 分布式 ID（Leaf）、分布式任务调度（XXL-JOB）、分布式协调（Zookeeper）、分布式消息队列（Kafka/RabbitMQ/Pulsar）、分布式搜索（Elasticsearch）、分布式链路追踪（SkyWalking）

高可用

限流、降级熔断、冷备、双机热备、同城双活、异地多活、容灾备份

高并发

  • 数据库：分库分表（ShardingSphere/MyCat）、读写分离
  • 缓存：缓存雪崩、缓存击穿、缓存穿透
  • 负载均衡：负载均衡算法、软硬件负载均衡

阶段 7：Java 求职

目标：找到好工作。

准备建议

  1. 提前规划：至少提前 3 个月准备，查看目标岗位 JD 了解要求
  2. 打磨简历：突出技术栈和项目亮点，量化成果
  3. 多刷面试题：重点刷 Java 集合、并发、JVM、Spring、MySQL、Redis、微服务
  4. 刷算法：坚持 LeetCode，每天 1-2 道
  5. 多看面经：了解真实面试被问的内容
  6. 多参加面试：先拿不太想去的公司练手，每次面试后复盘总结

经典面试题汇总

Java 基础：

  • == 和 equals 的区别
  • final 关键字
  • ArrayList vs LinkedList
  • HashMap 原理（JDK 7 vs 8）

并发编程：

  • volatile 关键字
  • synchronized 锁升级
  • 线程池参数设置
  • CAS 和 AQS

JVM：

  • JVM 内存模型
  • GC 流程
  • 双亲委派模型
  • 类加载过程

Spring：

  • IOC 和 AOP
  • Bean 生命周期
  • 设计模式应用

MySQL：

  • 索引最左原则
  • InnoDB vs MyIsam
  • 慢查询定位
  • 事务隔离级别

Redis：

  • 缓存三大问题（穿透/击穿/雪崩）
  • 数据结构
  • 持久化方式

消息队列：

  • 消息队列优缺点
  • 幂等性

微服务：

  • 注册中心的作用
  • 网关的作用
  • 分布式事务
