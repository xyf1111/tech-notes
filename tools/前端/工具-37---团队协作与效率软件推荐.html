工具 37 - 团队协作与效率软件推荐

集合两类真实软件清单，按「团队协作 / 内容创作 / 文件共享 / 效率提升 / 个人开发工具」五类给出选型理由：一家小团队在用的协作与创作软件（即时通信用企业微信、文档协作腾讯文档 + 飞书 + 语雀、内容创作 Typora + PicGo + MdNice + 剪映 + Draw.io / XMind、文件共享 iCloud / 腾讯微盘 / GitHub 私有仓库 / 网盘、效率提升 ChatGPT + 剪贴板历史工具）；以及个人日常开发常用的一批工具（Alfred、uTools、iTerm2 + Zsh、Navicat Premium、可编程宏键盘等）。

核心要点

一、团队协作

即时通讯：企业微信

  • 最主要的原因：能直接对接微信用户，这是其他通讯软件做不到的
  • 次要原因：操作习惯（在腾讯工作多年一直用企业微信，习惯早就养成了）

文档协作：腾讯文档 + 飞书 + 语雀同时用，按场景分工

平台用途选它的理由
腾讯文档内部协作 + 以公司为核心的收集表（如需求排期表、招聘内推表）能直接在企业微信中打开、共享协作，在公司内统一管理方便
飞书对外公开分享实时编辑体验好，支持公开分享知识库（多个文档），比较利于传播
语雀内部知识沉淀 + 对外知识分享在知识库方面体验最好，适合管理复杂的、成体系的系列文档资料

二、内容创作

  • 文章写作：本地用 Typora + Markdown 编写，保证多平台内容格式与排版一致；配 PicGo 图床实现本地文章图片自动上传（详见 工具 24 - Typora 与 PicGo 写作效率提升）
  • 多平台分发：写完用 MdNice 网站把 Markdown 格式的文章自动转换成公众号、知乎等平台支持的样式，再分发到多个平台
  • 视频：剪映（自动生成字幕很省事）
  • 编程式生成视频：Remotion——用前端代码（React）制作视频的库，适合数据驱动、批量化的视频生成；典型案例是 GitHub 年度总结视频项目 githubunwrapped.com（输入自己的 GitHub 用户名即可一键生成个人年度总结视频，展示最常用语言、开启 issues 数、关注仓库数、高效时段、提交与贡献次数等；实现原理 = 通过 GitHub GraphQL API 获取用户年度统计数据，再用 Remotion 渲染成视频）
  • 绘图与思维导图：流程图用语雀自带绘图功能或免费的在线绘图网站 Draw.io；思维导图用 XMind（收费但确实好用）（详见 工具 30 - 程序员绘图工具与技巧）
  • 公众号运营：壹伴浏览器插件——增强公众号后台，让文章排版、找素材、运营分析（如阅读数据分析）都更高效

三、文件共享

  • 个人跨设备：Mac 自带 iCloud 文件夹同步——办公文件全放在指定目录下就自动同步到 iCloud（类似手机相册云同步）
  • 团队文件：腾讯微盘（企业微信内置，给员工共享文件很方便）
  • 需要开源的文档：先通过 GitHub 私有仓库和团队内部协作，完善好了直接开源
  • 音视频等大文件：阿里云盘或百度网盘（不开会员会限存 + 限速，存储成本使然）

四、效率提升

  • ChatGPT：遇到 Bug 等任何问题都可以直接问它；团队要求把 AI 工具利用起来提高工作效率
  • 剪贴板历史：Mac 上用 Paste——保存所有复制粘贴记录，需要再次粘贴时用快捷键搜索即可（写代码、服务用户都很有用）；Windows 上的同类软件是 Ditto
  • 同类跨平台剪贴板工具见 工具 03 - 剪切助手：跨平台剪贴板管理工具
  • 任务与时间管理：滴答清单——界面精简、支持多端同步、使用方便且免费，用来代替「只靠大脑记事情」避免遗漏
  • 个人笔记应用选型（一位同学从格志 → flomo → Notion → 语雀的实测历程）：格志只有手机端，习惯在 PC 端码字的话撑不久；flomo 极简、纯文本 + 图片，适合快速记碎碎念，但不适合编程笔记；Notion 扩展性很强却容易水土不服；语雀最终成为长期主力——交互简单明了、编辑器丰富、知识库体验好，个人记录与成体系的知识沉淀都合适（与上文团队文档协作用同一套工具，切换成本更低）。工具只是载体，配合打卡等外部机制，才真正把持续记录与输出的习惯养起来

五、个人开发与效率工具

作者日常开发中最常用的几个效率工具（编辑器与 IDE 的选型见 工具 36 - 代码编辑器与 IDE 一览，此处不重复）：

工具类型用它的理由
Alfred（Windows 对应 Ditto）Mac 启动器记录很长一段时间内所有复制过的内容并选择性粘贴，可搜索复制历史、查看详情；还支持自定义语法提示、配置工作流，能大幅提效
uTools跨平台工具集插件式设计，内置大量提效工具（一键搜索电脑全部文件、截图、翻译等），按需安装功能让软件保持轻小
iTerm2 + Zsh + Oh My ZshMac 终端Mac 自带终端难用，iTerm2 功能齐全、简洁美观；搭配 Zsh + Oh My Zsh 可定制主题、使用更多强大功能
Navicat Premium数据库管理跨平台，在单一软件中管理 MySQL、MariaDB、PostgreSQL 等主流数据库，方便编写执行 SQL、导入导出数据，是后台开发必备（需付费）
可编程宏键盘硬件外设键位扩展：按一下自动敲出一套组合键，把高频操作固化成快捷键
