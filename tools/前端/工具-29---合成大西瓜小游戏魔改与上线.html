工具 29 - 合成大西瓜小游戏魔改与上线

本文从 0 到 1 带你下载开源的「合成大西瓜」小游戏源码（基于 cocos2d 游戏引擎），在本地把它跑起来，再通过修改 project.js 实现改分数、换图片、无敌模式、控制水果生成等魔改，最后免费发布上线分享给朋友。

游戏简介与总体思路

「合成大西瓜」的玩法是俄罗斯方块、2048、水果忍者的结合：控制水果下落，两个相同的水果合成更大的水果，消除时带溅射效果。游戏本身是开源的，GitHub 上可直接搜索到源码，且基于 cocos2d 引擎、代码量不大，魔改基础功能非常简单。

整体分三步走：下载源码本地运行 → 动手魔改及原理分析 → 发布上线。

一、下载源码与本地运行

源码与目录结构

从 GitHub 下载源码后，整个代码目录并不复杂，只需了解几个关键文件：

文件作用
index.html整个项目的主页面
project.js项目核心代码，游戏逻辑都在这里（魔改主战场）
settings.js项目配置文件
res 目录存放图片和音频等资源

本地运行三步

直接双击 index.html 是无法运行游戏的，会卡在加载 99%。原因是双击打开时访问协议是 file 而不是 http，导致部分资源请求失败、文件缺失。所以需要在本地搭建一个 web 服务器，用 http 协议访问：

  1. 安装 Node 和 npm：Node 是服务端运行 JS 的引擎，npm 是依赖包管理工具。到 Node 中文网（nodejs.cn/download）下载 Node.js，会自动安装 npm；装完在命令行执行 npm -v 输出版本号即成功。

2. 替换图片

原理最简单：在 res 资源目录下找到原有图片，用相同名称、相同格式、相同尺寸的图片直接替换即可（网上很多创意玩法都是这么来的，如合成 B 站硬币等）。

3. 无敌模式

无敌模式 = 水果堆到顶部超出线条，游戏也不结束。在代码中搜索 end 找到游戏结束的判断条件表达式，运算结果为 true 则结束、false 则继续。更好的做法是额外增加一个条件判断（而不是改掉原有逻辑），例如加一个无敌开关变量，为真时强制不触发结束逻辑，方便随时开关。

4. 控制水果生成

想控制下一个生成的水果（比如每次都出大西瓜）？搜索 fruit、create 等关键字可定位到水果生成逻辑。要点如下：

  • 每个水果对应一个数字序号（下标），由小到大依次是 0-9，葡萄到西瓜。
  • 前 5 个水果的生成是固定的（类似新手教程），用 createFruitCount 统计，之后才开始随机生成。
  • 刚开始是两次 createOneFruit(0)（两次葡萄），后面随机生成葡萄（0）到西红柿（5）。
  • 想让第一个水果变成别的，直接搜索 createOneFruit(0)，把 0 改成其他数字即可。

5. 大水果合成小水果（倒着玩）

把游戏倒着玩：两个西瓜合成椰子，最终合成葡萄即胜利。水果膨胀可理解为”升级”，反转升级顺序即可。定位方法：搜索边界值（如 < 9）或关键词 LevelUp，找到水果合成逻辑，把 +1 改为 -1（每次合并由升级改为降级）。注意还要处理边界值：

  • 原本合成大西瓜后有特殊逻辑（如闪光特效），顺序反转后要把边界值由 9 改为 0；
  • 同时把初始生成的水果由小葡萄改为大西瓜，否则开局逻辑对不上。

三、发布上线

本地改好后，推荐两种最简单的免费发布方式：腾讯云静态网站托管 或 Vercel，都不需要购买域名和服务器，个人娱乐、用户量不大的话免费额度完全够用。

方式一：腾讯云静态网站托管

服务器在国内，带 CDN 加速。步骤：

  1. 进入腾讯云云开发（cloudbase）控制台（cloud.tencent.com/product/wh），点击立即创建、开通一个云环境（一定要开启免费资源），稍等片刻创建完成，再初始化静态网站服务。
  2. 安装命令行工具并登录： 在弹出的页面确认授权。
  3. 在云环境查看页面复制云环境 id，然后在 index.html 所在目录（如 daxigua）执行部署命令，将目录中的网站文件全部发布： <EnvID> 要替换为刚复制的云环境 id。看到成功结果后，点击生成的链接即可访问和分享。

方式二：Vercel

Vercel 是免费网站托管平台，部署后生成可访问的简短网址，还能绑定自己的域名。步骤：

  1. 安装 Vercel 命令行工具：
  2. 进入 index.html 所在目录（如 daxigua），发布网站： 期间会让你输入项目名称、是否修改配置等选项，一路回车即可。发布成功后会得到一个网址，打开就能玩，也可以直接分享给别人。

小结

通过这个小游戏，既能玩到各种奇思妙想的创意魔改，也能顺带学习一些编程知识。建议动手顺序：先本地跑通 → 改分数练手 → 换图片 → 再挑战合成逻辑和物理参数，逐步加深对 cocos2d 游戏结构和 project.js 逻辑的理解。
