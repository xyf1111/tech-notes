工具 34 - 编程学习网站与资源推荐

从入门教学、开源资源检索、技术文章社区到刷题求职的网站清单，外加 9 个值得长期收藏的开源教程仓库（Java / 前端 / Python / SQL / Docker / AI / Go）和 4 个面向程序员的英语学习项目，以及 3 个值得关注的前端团队开源项目与 10 余个创意练手开源项目——自学编程时按「学 → 查 → 读 → 练」四个环节各取所需。

核心要点

一、学习类网站（入门教学）

网站地址特点
freeCodeCamphttps://chinese.freecodecamp.org/免费实战学编程，课程丰富，尤其适合想学前端 web 开发的同学；每小节有教学 + 代码示例 + 在线写代码完成任务，像玩游戏闯关
菜鸟教程https://www.runoob.com/简洁却不简单：前端、Java、Python、C++、PHP 等主流语言的文档教程全免费，附大量可直接在线练习的代码示例
W3CSchoolhttps://www.w3cschool.cn/多元化教学网站，免费在线文档教程多，支持手机端学习；实战训练为闯关模式，适合新手（同名的 W3School 年久失修，相对一般）
慕课网https://www.imooc.com/各编程方向的免费入门/进阶视频教程，学习过程中可记录笔记、阅读他人笔记，帮助养成记录习惯
蓝桥云课https://www.lanqiao.cn通过做实验学编程：使用真实的云服务器环境写代码、开发项目，比看书印象更深
programming-idiomshttps://programming-idioms.org/收录 30 多种语言、250+ 个常用代码片段（idiom = 惯用法）的对照网站：同一功能可横向比较各语言实现（如复制文件用 Python 一行搞定）；既能查看某门语言的全部常用代码片段（学新语言时巩固基础、学优秀写法），也能一键对比两种语言的语法差异（如 Java vs C++ 的打乱列表、随机取元素、判断列表是否包含某个值）
B 站https://www.bilibili.com/大量免费视频教程与优质知识分享博主，入门、项目、考研、大厂求职指南都有
知乎https://www.zhihu.com/topic/19554298没有系统教学，但有大量编程学习心得、经验分享与程序员相关讨论，适合了解行业全貌

另见 自学编程的入门方法 的「推荐学习网站」小节。

二、资源类平台（查资料 / 找项目）

平台地址特点
GitHubhttps://github.com/世界一流代码开源平台，数亿公开仓库；可搜索代码参考学习、上传代码共享、协作开发，也能搜到学习笔记、趣味项目甚至「不加班公司名单」
Giteehttps://gitee.com/软件开发协作平台，可理解为国内版 GitHub；同样支持搜索、共享、协作，项目数不及 GitHub 但访问速度更快
菜鸟工具https://c.runoob.com/汇总程序员常用开发工具：各语言在线代码编辑器、代码转换、格式化工具等，随用随取（类似的还有 BeJSON，收藏一个即可）
开发者搜索https://kaifa.baidu.com/厌倦搜索广告时的替代品：纯净无广告、专为开发者定制搜索结果，让技术搜索更简单高效
HelloGitHubhttps://hellogithub.com/人工维护的编程项目推荐网站，可分类浏览有趣、入门、优质的开源项目；每月发布一期「项目全家桶」推荐各语言好项目

在线编写/运行代码的平台见 工具 33 - 在线编程网站与在线 IDE。

三、技术文章与社区

网站地址特点
CSDNhttps://www.csdn.net/搜索编程问题时命中率最高的中文站；看技术博客、下载资料、提问题、看教程，也可开通自己的博客
掘金https://juejin.cn/专注分享编程技术文章，覆盖前端、后端、架构、AI 等上百个分类，前端优秀作者尤其多
博客园https://www.cnblogs.com/经典程序员博客网站，界面陈旧但文章丰富，可轻松打造自己的专属博客记录学习心得与代码笔记
InfoQhttps://www.infoq.cn/国内相对高端的软件开发文章与资讯站点，偏前沿技术、企业技术与工程思考；另有免费电子书、大咖直播回放
开源中国https://www.oschina.net/国内开源技术交流社区：最新软件发展/更新资讯、前沿技术文章、各类优质开源项目搜索

四、刷题与求职

网站地址特点
LeetCodehttps://leetcode-cn.com/一流的在线刷题、学算法网站，每个知识点都有专题教程；建议看完教程即时练习、举一反三
牛客网https://www.nowcoder.com/求职找工作平台：学编程、做习题、刷算法，还能看各公司各方向的面试题与面试经验，并参与内推、在线笔试、模拟面试

算法学习路线见 算法与数据结构 01 - 学习路线，求职相关内容见 编程学习与求职架构。

五、优质开源教程仓库（可直接在线阅读）

项目地址说明
JavaGuidehttps://javaguide.cn/全面的 Java 指南：帮初学者了解完整知识体系、帮求职者准备面试；作者准备面试时开源，如今已成为 GitHub 超 10 万 star 的顶流项目
LeetBookhttps://leetcode-cn.com/leetbook/轻松学算法的在线小书：分阶段、按知识点的入门教程，有图解、视频与他人题解，可选任意语言随时在线练习；另附《图解算法数据结构》等免费小书
被删的前端游乐场http://www.godbasin.com/同事小姐姐的前端文章合集，几百篇：新手入门教程、前端深入理解、领域解决方案与技术分享
Python 100 dayshttps://github.com/jackfrued/Python-100-Days分阶段 Python 入门教程：基础、进阶、开发框架、爬虫、数据分析、人工智能、项目管理；每天内容小而精，适合时间不多、想持续学习或巩固复习的同学
GitHub 漫游指南https://github.com/phodal/github在线小书，不是枯燥的 GitHub 教程，而是结合作者使用 GitHub 一万多小时的亲身经历，讲使用技巧、打造自己的项目、探索编程可能性
SQL 自学网http://xuesql.cn/边学边练、实时查看运行结果，用最快速度学会数据库与 SQL 基本使用（对应路线见 MySQL 15 - 学习路线）
Docker 从入门到实践https://vuepress.mirror.docker-practice.com/可在线阅读的 Docker 教程，含常见问题总结、热门开源镜像、工作中积累的最佳实践
《动手学深度学习》https://github.com/d2l-ai/d2l-zh完全开源的人工智能零基础入门教程，全中文、可在线阅读，已被全球近 200 所大学用于教学；附大量练习与源码，边学边练
地鼠文档https://www.topgoer.cnGo 语言学习资源合集网站：入门教程、代码示例、框架、类库、中文文档、算法、面试题、电子书，可在线阅读与免费下载

Java 方向的文档教程与实战项目另有单独汇总，见 Java 47 - Java 学习资源与项目汇总。

六、程序员英语学习资源（GitHub 开源项目）

英语能力直接影响日常交流、变量命名、读英文文档与晋升答辩的表达；下面 4 个项目覆盖「兴趣启发 → 系统提升 → 方法训练 → 词汇手册」四个层次，均可在 GitHub 免费在线阅读。

项目地址说明
人人都能用英语https://github.com/xiaolai/everyone-can-use-english近 5k star 的在线小书，不是单词书也不是练习册，而是从口语、语音、朗读、词典、语法、精读等方面给你启发，带你重新认识和理解英语；在啃厚厚的单词书之前不妨先读它
英语提升诀窍https://github.com/byoungd/English-level-up-tips-for-ChineseGitHub 上最受欢迎的英语学习项目（近 20k star）：从认知、单词、听力、阅读、口语五方面重识英语，并给出高效学习建议与配套资源（英文脱口秀、电影、YouTube 频道、英文原版书等），20 分钟即可读完
程序员英语学习指南https://github.com/yujiangshui/A-Programmers-Guide-to-English近 10k star，专为程序员编写的英语学习指南：深挖语言学习本质（多用中文举例、以程序员易理解的方式思考），给出可自行推演的训练方法；核心观点是「语言学习没有技巧」，关键是按本质设计适合自己的方法并用以甄别网上的资料
程序员工作中常见的英语词汇https://github.com/Wei-Xia/most-frequent-technology-english-words面向程序员的英语词汇手册：收集计算机书籍、文档、文章中的高频技术词汇，目标是掌握后无障碍阅读英文技术文章与文档；不要死记硬背，工作中遇到时对照着读几遍即可

七、值得关注的前端团队开源项目（知识渠道）

腾讯新闻中台前端团队（TNTWeb，GitHub 组织 tnfe）在 GitHub 上公开了几个可持续阅读的前端项目，适合用来感知前沿动态、拓宽技术名词量：

项目地址说明
TNT-Weeklyhttps://github.com/tnfe/TNT-Weekly持续更新的前端周刊：官方精选 web 前端领域（含 H5、小程序等）的国内外技术文章、开源项目与前端技巧，帮读者过滤无意义信息；进仓库可直接挑往期读，如「React 运行时优化方案的演进」「从零到一实现企业级微前端框架」
FEDiagramhttps://github.com/tnfe/FEDiagram「图说前端」：用图画的方式讲清前端开发中晦涩难懂的知识细节，共 15 期、每期一个主题配几张知识图（如第 4 期讲 ES3 / ES5 / ES6 的区别）；已停更，但已整理的 15 期仍值得读
awesome-blackmagichttps://github.com/tnfe/awesome-blackmagic前端「奇技淫巧」合集：作者把开发中常用的技巧称为「魔法」，按语言、框架分类（黑魔法 = js / ts 相关，蓝魔法 = 框架相关），收录实用 JavaScript 小技巧与有趣的技术实践；也已停更

为什么值得读技术周刊：除了具体知识，最大的好处是多接触名词——有些技术你没用上，可能只是不知道它的存在；看到新词之后，用「搜索 → 阅读 → 实践」一套组合拳就能把它拿下。

八、开源创意项目推荐（练手思路启发）

自学时不知道该做什么项目？网上 Java 项目多是商城、博客、管理系统，同质化严重、功能基础还 Bug 层出不穷。下面这些非业务型开源项目脑洞大、结构规整、代码规范，适合作为练手素材与思路启发（按项目名在 GitHub 搜索即可）。评级为源作者的参考值：难度 · 创意 · 实用。

项目方向技术栈评级说明
windows11前端React + CSS Modules⭐️⭐️ · ⭐️⭐️⭐️⭐️ · ⭐️能直接在浏览器里运行的 Windows 11，界面与体验高度还原，还能浏览网页、打开 VS Code 写代码；技术并不复杂（主流前端技术 + iframe 内嵌实现高级功能），胜在项目结构规范清晰，适合学前端
air-conditioner前端React + TypeScript + Sass + Redux + Material UI⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️⭐️ · ⭐️曾刷屏朋友圈的「云空调」，只有一个页面却用上不少前端主流技术；打开小空调还会触发真实的吹风音效
codelf前端React + Gulp + Animate.css + SearchCode⭐️⭐️ · ⭐️⭐️⭐️ · ⭐️⭐️变量命名神器：输入中英文词汇，自动推荐合适的英文变量名；原理是先用翻译插件把中文翻成英文，再拿英文单词请求 SearchCode 代码搜索服务
bytemd前端Vue / React / Svelte + TypeScript + Rollup⭐️⭐️⭐️⭐️ · ⭐️⭐️ · ⭐️⭐️⭐️⭐️字节跳动开源的富文本编辑器组件：与掘金写作风格一致、同时支持 Markdown 与傻瓜式操作、支持多主题、插件式设计可按需定制，且适配原生与主流框架（含 Svelte）；编辑器选型对比见 工具 39 - 富文本编辑器选型（开源免费）
QR-Code-generatorJavaJava 基础 + 算法⭐️⭐️⭐️ · ⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️支持多种主流编程语言的二维码生成器类库，几行代码就能生成二维码；几乎不用第三方类库、纯手写实现二维码生成算法，适合对算法感兴趣的同学
arthasJavaJava + Maven + Netty⭐️⭐️⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️阿里开源的 Java 线上诊断利器：分析线上 Java 程序的信息与异常、不重启项目直接热修复问题；用到了探针等 Java 高级知识，属于「能打动面试官」的项目——先从会用它开始，再了解底层原理，最后自己做一个
mybatis-generatorJavaJava + Maven + MyBatis + JavaParser⭐️⭐️⭐️⭐️⭐️ · ⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️⭐️MyBatis 官方推出的代码生成器，快速生成重复的增删改查代码、减少工作量；「如何更优雅灵活地生成通用代码」很有门道，官方源码值得一读（另 MyBatis Plus 也很好用）
thefuckPythonPython⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️⭐️ · ⭐️⭐️自动修正命令行错误的工具：不小心输错命令后再输入一次 fuck，就会自动执行正确的命令；99.9% 纯 Python 实现，目录结构与代码规范都很规整，适合有一定基础的同学学习
avatarifyPythonPython + Shell + 人工智能⭐️⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️⭐️ · ⭐️⭐️给一张图片、打开摄像头，图片中的人物就能跟着你的表情动起来；虽用到人工智能技术但不必深究那部分，Python 代码文件不多，适合学了一段时间 Python 的同学练手
askgit其他Go + SQLite⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️⭐️ · ⭐️⭐️⭐️用 SQL 语言查询 Git 仓库信息的工具（可在线使用）：把 Git 信息存储成数据库中的一张表，从而支持 SQL 统计分析，让只会 SQL 的同学摆脱复杂难记的 Git 查询语言；做这类工具除了编程语言，还要懂些 SQL 与 Git
