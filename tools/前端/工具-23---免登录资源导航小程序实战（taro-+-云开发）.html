工具 23 - 免登录资源导航小程序实战（Taro + 云开发）

用 Taro + Taro UI 开发一个所有用户都能查看和推荐资源的微信小程序，后端采用腾讯小程序云开发，无需自建服务器，并通过云开发未登录模式实现免登录访问，帮助快速了解小程序开发流程与云开发技术。

技术选型

  • 前端：Taro 框架 + Taro UI。Taro 是基于 React 的跨端开发框架，写一套代码可自动生成微信小程序、H5、APP 等应用，且为很多复杂功能提供了函数封装，提升开发效率；Taro UI 是基于 Taro 的 UI 库，提供图片上传、选择器等现成组件，满足常见开发需求。
  • 后端：腾讯小程序云开发。传统方式用 SpringBoot、Laravel、Django 等框架需要自己搭建服务器、数据库、日志、监控、运维，对只懂前端或想快速开发的同学门槛太高；云开发免去这些负担，专注实现功能本身。

云开发优势

小程序云开发是微信团队联合腾讯云推出的专业小程序开发服务，原生打通微信开放能力，优势：

  1. 免后端服务器：直接使用平台提供的云数据库、云存储、音视频、AI 等能力快速开发业务。
  2. 安全易接入：无需管理证书、签名、密钥，直接调用微信 API，复用微信私有协议及链路保证安全性。
  3. 多端复用：支持环境共享，一个后端环境可开发多个小程序、公众号、网页，便捷复用业务代码与数据。
  4. 不限语言框架：可用任意语言和框架开发，构建为容器后快速托管至云开发。
  5. 按量计费：成本更低，支持自动扩缩容。
  6. 扩展能力：支持一键部署静态网站，并能用云 CMS 管理数据内容。

例如查询数据，直接用云开发 SDK 几行代码即可完成。

免登录模式

按上述流程开发完成后，开发者工具中可正常推荐和展示资源；但上线分享给其他用户后会出现权限问题、功能全部失效——因为云开发制定了安全规则，默认不允许未登录用户访问。若小程序分享到朋友圈，要求朋友登录才能看资源列表，体验太差，因此需要实现无登录调用。

云开发为此提供了 未登录模式，该模式下不存在用户登录态，应用场景：

  1. 单页模式：小程序/小游戏分享到朋友圈被打开时。
  2. Web 未登录模式：没有登录的 Web 环境中。

该模式默认关闭，需在「云控制台 - 设置 - 权限设置」中手动为云环境开启允许未登录访问。

安全规则

开启未登录模式后，客户端（前端）的权限控制必须使用安全规则：云函数、数据库和文件存储的访问都必须通过安全规则。因此除了控制台开启允许未登录访问外，还需在云数据库、云存储和云函数的权限设置中分别选择安全规则并配置。

安全规则语法（以云数据库为例，选择自定义安全规则）：

  • read / write：分别代表读写权限。
  • doc：表示当前的一条数据。
  • auth：表示当前登录的用户。
  • 表达式为 true 时允许访问。

默认规则下，当前登录用户必须是该条数据的创建者才能读写。未登录用户访问时 auth 字段为空，若要允许所有用户读写所有资源，直接将表达式值设置为 true。

各资源规则配置：

  • 云数据库：将规则表达式改为 true，允许所有用户读写。
  • 云存储：resource 表示一个资源，将表达式改为 true，允许所有用户读写存储的所有文件。
  • 云函数：可为不同函数设置不同规则，例如 login 函数允许所有用户访问，其他函数仅允许已登录用户访问。

安全规则非常灵活，合理运用可在满足资源调用需求的同时增加资源安全性。
