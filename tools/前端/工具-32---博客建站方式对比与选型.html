工具 32 - 博客建站方式对比与选型

搭建个人博客网站主要有 5 种方式：自己开发、站点生成器、建站程序、建站平台、直接购买，各有优劣。按「省事 / 省钱 / 简易 / 灵活」四个维度对比选型，追求扩展性选开源建站程序，追求省心省钱选静态站点生成器。

五种建站方式

1. 自己开发

自己写代码（前台 + 后台管理）、自己发布上线、自己维护，啥都自己干。

  • 优点：代码掌握在自己手里很安全；想加什么功能不受限制、很灵活
  • 缺点：最麻烦，开发 + 上线 + 维护全包
  • 适合：自学编程的同学练手（博客功能丰富且典型：登录、评论、标签），也可基于 GitHub 开源项目二次开发；只想快速写文章则没必要

2. 站点生成器

大佬将博客的通用功能（如文章管理）抽象成站点生成器，用极少的命令 + 配置文件即可自动生成精美网站：

  • 博客站：Hexo、Hugo
  • 文档站：Docsify、VuePress、Dumi

绝大多数站点生成器只能生成静态网站（内容固定、无需从数据库动态获取），因此优点突出：

  • 省钱：文件扔 GitHub Pages、Gitee Pages 等即可免费部署
  • 速度快：省去数据动态获取过程，配合 CDN 加载飞快
  • SEO 好：静态页面更容易被搜索引擎蜘蛛抓取、稳定排名
  • 易维护：功能纯粹，比动态网站好维护

缺点：内容需提前确定、不能动态添加；功能纯粹导致交互性弱，可配合插件实现评论、全文检索等功能。对博客来说静态网站基本够用。

具体搭建教程见 工具 13 - Hexo 博客搭建教程、工具 22 - Docsify 文档网站搭建、工具 27 - VuePress 文档网站搭建。

其中的 Dumi 是阿里推出的文档站生成工具，同样输入几行命令就能得到文档网站，但和 Docsify 不同：它专为组件开发场景而生（可嵌入和折叠代码块、提供组件在终端中的浏览效果），很适合作为组件库文档，生成的站点精简、封面支持自定义特性展示，因此也很适合作为项目或产品的官方文档。

3. 建站程序

快速做动态博客的现成程序，主流推荐 WordPress，轻量可选 Typecho：

  • 按官方文档一键安装 → 引导式初始化配置 → 挑选主题美化
  • 后台直接发布和管理文章，用户管理、分类、标签、评论等功能开箱即用
  • 可装插件扩展（发邮件、表单收集等），必要时自己改源码
  • 主题丰富：后台点一下即可从 8000 多个免费主题中随意切换
  • 插件生态强：投票、表单、邮件发送、第三方登录、安全防护、搜索引擎优化等功能都能靠插件补齐，甚至可以用 Elementor 插件可视化制作页面
  • 强大到很多云服务器已自带 WordPress 镜像，连安装和部署都省了；小到个人博客、大到企业电商平台都可以轻松实现

4. 建站平台

线上拖拽式建站平台，不用安装任何东西，套模板 + 界面拖拽即可出网站，平台提供域名、一键上线，维护也全包。适合完全不想碰技术、专注内容的场景（如凡科建站）。

5. 购买

花钱找工作室/个人开发者做网站，常见渠道：

  • 云服务提供商（如 BAT 云官网）：大厂相对专业靠谱，更推荐
  • 建站主题官网（收费模板 + 专业建站服务）
  • 某宝（价格一般较贵）

对比表格

从四个维度对比（星星越多越优秀）：

方式省事省钱简易灵活

选型建议

  • 自主开发最灵活但最麻烦；站点生成器最省钱（大量免费静态托管服务）；直接购买最省事但最费钱、后续修改难；开源建站程序 / 建站平台相对均衡，方便易用且功能齐全
  • 后续计划深度定制（自己写代码扩展）→ 选开源建站程序（如 WordPress）
  • 只想低成本快速写文章 → 选站点生成器 + 免费静态托管（部署方式见 DevOps 06 - 免费上线网站的几种方法）

附：现成建站与配套工具补充清单

除了上述五种方式，还有一批开箱即用的工具可以省掉重复搭建的麻烦：

页面 / 首页生成器

  • Img Cook（阿里）：运用人工智能技术，上传一份设计稿（PS、Sketch、图片等格式均可）即可一键生成对应的网页代码文件，生成后还能随意编辑网页的内容、样式和事件；阿里曾用它生成双 11 会场的新页面，90% 以上的代码能直接用。
  • Ant Design Landing（蚂蚁）：网站首页生成器，提供丰富首页模板，选中模板后可可视化编辑页面元素，还能一键发布并借助 Vercel 获得默认可访问域名，免买域名和服务器（注意把生成地址中的 antlanding 去掉，否则无法访问）；生态定位见 工具 05 - Ant Design Pro 入门与初始化 的「Ant Design 生态体系」。

后台管理脚手架

企业开发中「有前台通常就有后台」（如用户管理、商品管理、数据分析），因此现成的后台管理平台非常多，各种语言、各种框架实现的基本都有，例如 vue-element-admin、react-admin、go-admin 等，基本都是开箱即用，能省去重复搭建管理后台的麻烦。
