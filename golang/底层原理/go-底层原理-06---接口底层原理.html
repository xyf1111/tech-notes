Go 底层原理 06 — 接口底层原理

eface 与 iface

Go 接口在运行时由两种结构体表示：

eface（空接口 interface{}）

iface（有方法的接口）

接口值的内存布局

nil 接口 vs 有类型 nil

p 的值：
┌─────────────┐
│ _type = nil  │     ← 类型信息是 nil
│ data  = nil  │
└─────────────┘

i 的值（赋值后）：
┌─────────────┐
│ _type = *int │     ← 类型信息是 *int，非 nil！
│ data  = nil  │
└─────────────┘

类型断言底层

底层流程

  1. 获取 eface._type 或 iface.tab._type
  2. 和目标类型比较 _type
  3. 如果匹配，从 data 指针拷贝值
  4. 不匹配返回零值 + false（或 panic）

接口比较

两个接口值相等当且仅当：

  1. 类型相同（_type 指向同一类型元数据）
  2. 值可比较且相等
