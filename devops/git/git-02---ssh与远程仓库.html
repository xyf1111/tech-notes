多远程仓库管理

添加多个远程仓库

一个本地仓库可同时关联多个远程仓库（如 GitHub + Gitee），实现同时推送：

在 IDEA 中配置多远程仓库

  1. 本地初始化 Git 仓库后，进入 Git → Manage Remotes
  2. 添加多个远程地址，分别命名（如 github、gitee）
  3. Push 时可选择推送到指定远程仓库
  4. 也可分别推送：先 Push 到 GitHub，再 Push 到 Gitee
